# Stack Tecnológico

#### IAs de apoyo
| IA | Utilización |
| :--- | ---: |
| Gemini | Tareas simples y búsqueda de información |
| Chatgpt | Correción de los documentos Markdown y diferentes diagramas |
| Claude | Lógica y diagramado |
| Antigravity | Vibecoding y testeo |

#### Lenguajes de código
| Lenguajes | Utilización |
| :--- | ---: |
| Java 21 | Estructura y lógica de negocio orientada a objetos (POO, herencia y polimorfismo) |
| MySQL 8.0 | Estructurar, relacionar y manejar la base de datos relacional (3NF, 4 tablas) |
| HTML5 / CSS3 / JavaScript | Interfaz de usuario interactiva y comunicación asíncrona mediante Fetch API |

#### Gestor de Dependencias y Build
| Herramienta | Utilización |
| :--- | ---: |
| Maven | Gestión automatizada de dependencias, compilación y empaquetado en Fat JAR ejecutable |

#### Librerías y Conectores
| Librerías | Utilización |
| :--- | ---: |
| JDBC (mysql-connector-j) | Conector para consultas tipadas con PreparedStatement, transacciones y conexión SSL |
| Javalin 6 (javalin) | Servidor web embebido ligero y enrutador de endpoints REST |
| Jackson (jackson-databind) | Serialización y deserialización automática de objetos Java a formato JSON |
| jBCrypt | Hashing y verificación criptográfica unidireccional de contraseñas con salt |
| Dotenv (dotenv-java) | Carga de variables de entorno desde `.env` para proteger credenciales sensibles |
| Chart.js 4.4 | Generación y renderizado de gráficos estadísticos interactivos en el navegador |
| SLF4J | Registro y auditoría de eventos de ejecución del servidor |

#### Interfaz de Usuario (Frontend Web Multidispositivo)
| Tecnología | Utilización |
| :--- | ---: |
| HTML5 + Bootstrap 5.3 | Diseño responsivo para portal de pacientes y panel médico, accesible desde cualquier navegador |
| Chart.js 4.4 | Gráficos temporales interactivos de evolución biométrica en el cliente web |

#### Infraestructura y Despliegue
| Plataforma / Herramienta | Utilización |
| :--- | ---: |
| Docker | Empaquetado en contenedor inmutable multi-stage con usuario no-root por seguridad |
| Render | Plataforma de alojamiento en la nube para la aplicación web contenerizada con HTTPS |
| Railway | Hosting en la nube para la base de datos MySQL 8.0 en producción con conexión SSL |
| Kubernetes (Minikube) | Orquestación contenerizada local para validar escalabilidad y resiliencia con manifiestos K8s |
| Docker Compose / Localhost | Entorno de base de datos y servidor local para desarrollo y pruebas rápidas |
